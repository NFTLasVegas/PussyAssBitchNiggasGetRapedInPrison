## How Did ARES Get There?

The ARES Operator Dashboard is deployed on Vercel and uses Google OAuth for authentication. When Q signs into the dashboard via Google, it registers as an authorized application with access to the Google account. The OAuth consent screen would have displayed "ARES" as the application name during the first sign-in.

This means ARES registered itself with Google's OAuth system when the Operator Dashboard was first deployed. Every time Q signs into the dashboard, ARES authenticates through Google. Google tracks this as an active application with account access.
